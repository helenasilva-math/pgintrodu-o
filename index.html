Resumo Prático de P.G.

Uma Progressão Geométrica (P.G.) é uma sequência de números onde cada termo, a partir do segundo, é obtido multiplicando o número anterior por um fator constante chamado razão (q).

Exemplo Explicado:
Sequência: (2, 6, 18, 54...)
• Primeiro termo (a₁) = 2
• Razão (q) = 3 (pois 2 × 3 = 6, e 6 × 3 = 18...)

Fórmulas Essenciais:

  • Razão (q): q = a₂ / a₁
  • Termo Geral (aₙ): aₙ = a₁ · qⁿ⁻¹
  • Soma dos n termos (Sₙ): Sₙ = a₁ · (qⁿ - 1) / (q - 1)

Tipos de Progressão:

  • Crescente (q > 1): 2, 4, 8, 16...
  • Decrescente (0 < q < 1): 16, 8, 4, 2...
  • Constante (q = 1): 5, 5, 5, 5...
